Faire fonctionner la base de donnée.

Etape 1:
Installer xampp
https://www.apachefriends.org/

Etape 2:
Lancer xampp puis clicker sur start
au niveau de Apache et de MySQL.
(Autorisé si un message apparait puis relancer MySQL)

Etape 3:
Mettre la bdd sur phpmyadmin:
 - Cliquer sur nouvelle table puis sur l'onglet exporter
 - Selectionner le fichier sql mis dans Asset > ODON > BDD > odonbdd.sql
 - Descendre tout en bas puis cliquer sur importer

Etape 4:
Sur xampp, ouvrir Explorer puis cliquer sur le dossier htdocs.
Créer un dossier odonbdd et mettre le Login.php

Etape 5:
Lancer unity et se connecter avec son compte.
un compte peut être ajouter dans la BDD si besoin.
Pour tester vous pouvez inscrire; identifiant : mdelm01, mot de passe : test.
