Attributs protégés hérités de UnityEngine.XR.Interaction.Toolkit.Utilities.BaseRegistrationList< T >
List< T > m_BufferedAdd
 List with buffered items to be added when calling Flush. The count of items shall only change upon a call to AddToBufferedAdd, RemoveFromBufferedAdd or ClearBufferedAdd. This list can be null, use bufferedAddCount to check if there are elements before directly accessing it. A new list is pooled from s_BufferedListPool when needed.
List< T > m_BufferedRemove
 List with buffered items to be removed when calling Flush. The count of items shall only change upon a call to AddToBufferedRemove, RemoveFromBufferedRemove or ClearBufferedRemove. This list can be null, use bufferedRemoveCount to check if there are elements before directly accessing it. A new list is pooled from s_BufferedListPool when needed.
