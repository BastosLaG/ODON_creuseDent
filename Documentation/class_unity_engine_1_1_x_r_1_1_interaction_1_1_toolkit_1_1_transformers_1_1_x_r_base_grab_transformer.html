Description détaillée

Abstract base class from which all grab transformer behaviors derive. Instances of this class can be assigned to an XRGrabInteractable using the Inspector by setting the Starting Single Grab Transformers (XRGrabInteractable.startingSingleGrabTransformers) and Starting Multiple Grab Transformers (XRGrabInteractable.startingMultipleGrabTransformers). This serves as a serializable reference instead of using the runtime list of grab transformers which is not serialized.

registrationMode
Valeurs énumérées
None 

Do not automatically register with the interactable. You will need to manually add it through code or by adding a reference to XRGrabInteractable.startingSingleGrabTransformers or XRGrabInteractable.startingMultipleGrabTransformers.

Single 

Register as a grab transformer used when there is a single interactor selecting the object.

Multiple 

Register as a grab transformer used when there are multiple interactors selecting the object.

SingleAndMultiple 

Register as a grab transformer used both when there are multiple interactors selecting the object or a single interactor selecting the object.

Called by Unity each time the number of selections changes for the given Interactable while grabbed by at least one Interactor, including when it is first grabbed. Use this to do any code initialization based on each Interactor currently selecting the Interactable, for example computing the initial distance between both Interactors grabbing the object.

Paramètres

targetPoseThe current target pose for the current frame.
localScaleThe current target scale of the Interactable's transform relative to the GameObject's parent.
There will always be at least one Interactor selecting the Interactable when this method is called. In other words, this will be called when the selection count changes from 0 to 1 and whenever it subsequently changes while still above 0. This method is called by Unity right before Process if the selection count changed.
