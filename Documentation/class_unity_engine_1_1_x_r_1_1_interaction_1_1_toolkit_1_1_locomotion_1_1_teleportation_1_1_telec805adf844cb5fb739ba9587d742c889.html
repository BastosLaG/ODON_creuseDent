Référence de la classe UnityEngine.XR.Interaction.Toolkit.Locomotion.Teleportation.TeleportVolumeDestinationSettings

Propriétés

bool enableDestinationEvaluationDelay [get, set]
 Whether to delay evaluation of the destination anchor until the user has hovered over the volume for a certain amount of time.
float destinationEvaluationDelayTime [get, set]
 The amount of time, in seconds, for which the user must hover over the volume before it designates a destination anchor. Only used if enableDestinationEvaluationDelay is true.
bool pollForDestinationChange [get, set]
 Whether to periodically query the TeleportationMultiAnchorVolume.destinationEvaluationFilter for its calculated destination anchor. If the determined anchor is different from the current TeleportationMultiAnchorVolume.destinationAnchor, the volume will initiate re-evaluation of the destination anchor.
float destinationPollFrequency [get, set]
 The amount of time, in seconds, between queries to the TeleportationMultiAnchorVolume.destinationEvaluationFilter for its calculated destination anchor. Only used if pollForDestinationChange is true.
Object destinationFilterObject [get, set]
 The object reference to the filter used to evaluate a teleportation destination. This object should implement the ITeleportationVolumeAnchorFilter interface. If this object is null, the volume will use a FurthestTeleportationAnchorFilter to evaluate the destination.
ITeleportationVolumeAnchorFilter destinationEvaluationFilter [get, set]
 The filter used to evaluate a teleportation destination from the list of anchors. If this is null, the volume will use a FurthestTeleportationAnchorFilter to evaluate the destination.

◆ destinationFilterObject

Object UnityEngine.XR.Interaction.Toolkit.Locomotion.Teleportation.TeleportVolumeDestinationSettings.destinationFilterObject
getset

The object reference to the filter used to evaluate a teleportation destination. This object should implement the ITeleportationVolumeAnchorFilter interface. If this object is null, the volume will use a FurthestTeleportationAnchorFilter to evaluate the destination.

To access and modify the destination filter at runtime, the destinationEvaluationFilter property should be used instead.
