Description détaillée

Interface to implement allocator performance tests which will run using BenchmarkAllocatorRunner<T>.Run(BenchmarkAllocatorType, int, int, int[]). Deriving tests from this interface enables both Performance Test Framework and Benchmark Framework to generate and run tests for the contexts described by BenchmarkAllocatorType.
