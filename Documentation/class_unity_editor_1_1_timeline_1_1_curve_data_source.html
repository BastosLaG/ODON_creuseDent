◆ GetClipVersion()

virtual UInt64 UnityEditor.Timeline.CurveDataSource.GetClipVersion ( )
virtual

The clip version is a value that will change when a curve gets updated. it's used to detect when an animation clip has been changed externally.

Renvoie
A versioning value indicating the state of the curve. If the curve is updated externally this value will change.

Réimplémentée dans UnityEditor.Timeline.ClipParametersCurveDataSource, et UnityEditor.Timeline.TrackParametersCurveDataSource.
