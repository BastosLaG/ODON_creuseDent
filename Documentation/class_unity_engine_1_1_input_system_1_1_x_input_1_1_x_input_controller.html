Description détaillée

An XInput-compatible game controller.

Note that on non-Microsoft platforms, XInput controllers will not actually use the XInput interface but will rather be interfaced with through different APIs – on OSX, for example, HID is used to interface with Xbox controlllers. In those cases, XInput-specific functionality (like Capabilities) will not be available.

On Windows, XInput controllers will be reported with InputDeviceDescription.interfaceName set to "XInput" and with a JSON representation of XINPUT_CAPABILITIES available in InputDeviceDescription.capabilities. This means that you match on those subType and/or flags for example.

// Create an XInput-specific guitar layout subtype.
// NOTE: Works only on Windows.
InputSystem.RegisterLayout(@"
{
""name"" : ""XInputGuitar"",
""displayName"" : ""Guitar"",
""extend"" : ""XInputController"",
""device"" : {
""interface"" : ""XInput"",
""capabilities"" : [
{ ""path"" : ""subType"", ""value"" : ""6"" }
]
}
}
");

Now, when an XInput controller is connected and reports itself with the subtype "Guitar", it is turned into an "XInputGuitar" instead of an "XInputController".

Valeurs énumérées
Unknown 

The controller type is unknown.

Gamepad 

Gamepad controller.

Includes left and right stick as Gamepad.leftStick and Gamepad.rightStick, left and right trigger as Gamepad.leftTrigger and Gamepad.rightTrigger, directional pad as Gamepad.dpad, and all standard buttons (Gamepad.buttonSouth, Gamepad.buttonEast, Gamepad.buttonWest, Gamepad.buttonNorth, Gamepad.startButton, Gamepad.selectButton, Gamepad.leftShoulder, Gamepad.rightShoulder, Gamepad.leftStickButton, Gamepad.rightStickButton).

Wheel 

Racing wheel controller.

UnityEngine.InputSystem.Gamepad.leftStick x-axis reports the wheel rotation, Gamepad.rightTrigger is the acceleration pedal, and Gamepad.leftTriggerLeft Trigger is the brake pedal. Includes Directional Pad as Gamepad.dpad and most standard buttons (Gamepad.buttonSouth, Gamepad.buttonEast, Gamepad.buttonWest, Gamepad.buttonNorth, Gamepad.startButton, Gamepad.selectButton, Gamepad.leftShoulder, Gamepad.rightShoulder). Gamepad.leftStickButton and Gamepad.rightStickButton are optional.

ArcadeStick 

Arcade stick controller.

Includes a Digital Stick that reports as a Gamepad.dpad (up, down, left, right), and most standard buttons (Gamepad.buttonSouth, Gamepad.buttonEast, Gamepad.buttonWest, Gamepad.buttonNorth, Gamepad.startButton, Gamepad.selectButton). The Gamepad.leftTrigger and Gamepad.rightTrigger are implemented as digital buttons and report either 0.0f or 1.0f. The Gamepad.leftShoulder, Gamepad.rightShoulder and Gamepad.leftStickButton, Gamepad.rightStickButton are optional.

FlightStick 

Flight stick controller.

Includes a pitch and roll stick that reports as the Gamepad.leftStick, a POV Hat which reports as the Gamepad.rightStick, a rudder (handle twist or rocker) that reports as Gamepad.leftTrigger, and a throttle control as the Gamepad.rightTrigger. Includes support for a primary weapon (Gamepad.buttonSouth), secondary weapon (Gamepad.buttonEast), and other standard buttons (Gamepad.buttonWest, Gamepad.buttonNorth, Gamepad.startButton, Gamepad.selectButton). Gamepad.leftShoulder, Gamepad.rightShoulder and Gamepad.leftStickButton, Gamepad.rightStickButton are optional.

DancePad 

Dance pad controller.

Includes the Gamepad.dpad and standard buttons (Gamepad.buttonSouth, Gamepad.buttonEast, Gamepad.buttonWest, Gamepad.buttonNorth) on the pad, plus Gamepad.startButton and Gamepad.selectButton.

Guitar 

Guitar controller.

The strum bar maps to Gamepad.dpad (up and down), and the frets are assigned to Gamepad.buttonSouth (green), Gamepad.buttonEast (red), Gamepad.buttonNorth (yellow), Gamepad.buttonWest (blue), and Gamepad.leftShoulder (orange). Gamepad.rightStick y-axis is associated with a vertical orientation sensor; Gamepad.rightStick x-axis is the whammy bar. Includes support for Gamepad.selectButton, Gamepad.startButton, Gamepad.dpad (left, right). Gamepad.leftTrigger (pickup selector), Gamepad.rightTrigger, Gamepad.rightShoulder, Gamepad.leftStickButton (fret modifier), Gamepad.rightStickButton are optional.

GuitarAlternate 

Alternate guitar controller.

Similar to Guitar but supports a larger range of movement for the vertical orientation sensor.

DrumKit 

Drum kit controller.

The drum pads are assigned to buttons: Gamepad.buttonSouth for green (Floor Tom), Gamepad.buttonEast for red (Snare Drum), Gamepad.buttonWest for blue (Low Tom), Gamepad.buttonNorth for yellow (High Tom), and Gamepad.leftShoulder for the pedal (Bass Drum). Includes Gamepad.dpad, Gamepad.selectButton, and Gamepad.startButton. Gamepad.rightShoulder, Gamepad.leftStickButton, and Gamepad.rightStickButton are optional.

GuitarBass 

Bass guitar controller.

Identical to Guitar, with the distinct subtype to simplify setup.

ArcadePad 

Arcade pad controller.

Includes Directional Pad and most standard buttons (Gamepad.buttonSouth, Gamepad.buttonEast, Gamepad.buttonWest, Gamepad.buttonNorth, Gamepad.startButton, Gamepad.selectButton, Gamepad.leftShoulder, Gamepad.rightShoulder). The Gamepad.leftTrigger, Gamepad.rightTrigger are implemented as digital buttons and report either 0.0f or 1.0f. Gamepad.leftStick, Gamepad.rightStick, Gamepad.leftStickButton and Gamepad.rightStickButton are optional.
