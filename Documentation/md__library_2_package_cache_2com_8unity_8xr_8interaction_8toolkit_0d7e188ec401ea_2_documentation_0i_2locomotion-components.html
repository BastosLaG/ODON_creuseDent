Locomotion components

The locomotion components provided by the toolkit.

Topic Description
Locomotion Mediator Mediates locomotion requests across multiple locomotion providers.
Tunneling Vignette Controller Controls a visual vignette effect intended to mitigate motion sickness.
XR Body Transformer Manages movement of the XR Origin taking into account the locomotion provider requesting a move and, optionally, a physics-based [Character Controller](xref:class-CharacterController].
Locomotion providers The locomotion components providing different modes of locomotion.
Locomotion Interactors The interactor components used for locomotion.
Locomotion Interactables The interactable components used for locomotion.
