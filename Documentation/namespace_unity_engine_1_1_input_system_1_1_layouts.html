Delegate used by InputSystem.onFindLayoutForDevice.

Paramètres
descriptionThe device description supplied by the runtime or through InputSystem.AddDevice(InputDeviceDescription). This is passed by reference instead of by value to allow the callback to fill out fields such as InputDeviceDescription.capabilities on the fly based on information queried from external APIs or from the runtime.
matchedLayoutName of the layout that has been selected for the device or null if no matching layout could be found. Matching is determined from the InputDeviceMatchers for layouts registered in the system.
