EndPointType UnityEngine.XR.Interaction.Toolkit.Interactors.Visuals.ICurveInteractionDataProvider.TryGetCurveEndNormal ( out Vector3 endNormal,
bool snapToSelectedAttachIfAvailable = false )

Attempts to determine the normal at the endpoint of the curve. This method will transform the captured local direction of the normal on select if tracking a snapped attach point.

Paramètres
endNormalOutput parameter that will hold the normal vector at the curve's endpoint.
snapToSelectedAttachIfAvailableIf true, the method will attempt to snap to the selected attach point, if it's available.
Renvoie
Returns an EndPointType indicating the type of the endpoint where the normal was determined.

Attempts to determine the end point of the curve. The end point can be set to either an attach point or the end of a raycast hit.

Paramètres
endPointOutput parameter that will hold the end point vector.
snapToSelectedAttachIfAvailableIf set to true, the method will try to snap to the selected attach point, if available.
snapToSnapVolumeIfAvailableIf set to true, the method will try to snap to the nearest snap volume, if available.
Renvoie
Returns an EndPointType indicating the type of the end point determined.
