Description détaillée

Base for a behavior that implements a specific type of user locomotion. This behavior communicates with a LocomotionMediator to gain access to the mediator's XRBodyTransformer, which the provider can use to queue IXRBodyTransformations that move the user.

◆ TryEndLocomotion()

bool UnityEngine.XR.Interaction.Toolkit.Locomotion.LocomotionProvider.TryEndLocomotion ( )
protected

Attempts to transition this provider into the LocomotionState.Ended state. This succeeds if LocomotionProvider.isLocomotionActive was true when this was called.

Renvoie
Returns true if LocomotionProvider.isLocomotionActive was true when this was called, false otherwise.

After this provider enters the LocomotionState.Ended state, it will invoke locomotionEnded and lose access to the XRBodyTransformer. Then during the mediator's LocomotionMediator.Update in the next frame, the provider will enter the LocomotionState.Idle state, unless it has called TryPrepareLocomotion or TryStartLocomotionImmediately again.

◆ TryPrepareLocomotion()

bool UnityEngine.XR.Interaction.Toolkit.Locomotion.LocomotionProvider.TryPrepareLocomotion ( )
protected

Attempts to transition this provider into the LocomotionState.Preparing state. This succeeds if LocomotionProvider.isLocomotionActive was false when this was called.

Renvoie
Returns true if LocomotionProvider.isLocomotionActive was false when this was called, false otherwise.

If this succeeds, then the provider can enter the LocomotionState.Moving state either by calling TryStartLocomotionImmediately or by waiting for the mediator's next LocomotionMediator.Update in which the provider's LocomotionProvider.canStartMoving is true. When the provider enters the LocomotionState.Moving state, it will invoke locomotionStarted and gain access to the XRBodyTransformer.

Attempts to queue a transformation to be applied during the active XRBodyTransformer's next XRBodyTransformer.Update. The provider's transformationPriority determines when the transformation is applied in relation to others. The queue attempt only succeeds if the provider is in the LocomotionState.Moving state.

Paramètres
bodyTransformationThe transformation that will receive a call to IXRBodyTransformation.Apply in the next XRBodyTransformer.Update.
Renvoie
Returns true if the provider has access to the XRBodyTransformer, false otherwise.

This should only be called when locomotionState is LocomotionState.Moving, otherwise this method will do nothing and return false.

Paramètres

protected

Attempts to transition this provider into the LocomotionState.Moving state. This succeeds if LocomotionProvider.locomotionState was not already LocomotionState.Moving when this was called.

Renvoie
Returns true if LocomotionProvider.locomotionState was not already LocomotionState.Moving when this was called, false otherwise.

Calls the methods in its invocation list just before the XRBodyTransformer applies this provider's transformation(s). This is invoked at most once per frame while locomotionState is LocomotionState.Moving, and only if the provider has queued at least one transformation.
