Logic to check if the attempted poke interaction meets the requirements for a select action.

Paramètres
interactorThe interactor that is a candidate for selection.
pokableAttachPositionThe attach transform position of the pokable object, typically an interactable object.
pokerAttachPositionThe attach transform position for the interactor.
pokeInteractionOffsetAn additional offset that will be applied to the calculation for the depth required to meet requirements for selection.
pokedTransformThe target Transform that is being poked.
Renvoie
Returns true if interaction meets requirements for select action. Otherwise, returns false.
