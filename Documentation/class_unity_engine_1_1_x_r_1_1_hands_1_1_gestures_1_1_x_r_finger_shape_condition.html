bool UnityEngine.XR.Hands.Gestures.XRFingerShapeCondition.CheckCondition ( XRHandJointsUpdatedEventArgs eventArgs)

Checks if the XRFingerShape matches the targets in this condition.

The target values are checked in the order listed. The method will return false as soon as it finds one value that is different from the target by more than the tolerance.

Paramètres
eventArgsThe hand joint updated event argument that contains the latest hand data.
Renvoie
Returns true if all the finger shape conditions are met. Otherwise, returns false.
