◆ ProcessJoints()

void UnityEngine.XR.Hands.Processing.IXRHandProcessor.ProcessJoints ( XRHandSubsystem subsystem,
XRHandSubsystem.UpdateSuccessFlags successFlags,
XRHandSubsystem.UpdateType updateType )

Called after XRHandSubsystem.preprocessJoints is invoked and before XRHandSubsystem.updatedHands is invoked. Use extension methods to XRHandSubsystem, XRHand, and XRHandJoint in XRHandProcessingUtility to modify hand and joint data.

Paramètres
subsystemThe XRHandSubsystem that invoked this callback.
successFlagsThe current frame XRHandSubsystem.UpdateSuccessFlags that can be set depending on the result of processing joint data.
updateTypeThe XRHandSubsystem.UpdateType for the current frame.
