◆ InteractableFocusMode

enum UnityEngine.XR.Interaction.Toolkit.Interactables.InteractableFocusMode

Options for the focus policy of an Interactable.

Voir également
IXRFocusInteractable.focusMode
Valeurs énumérées
None 

Focus not supported for this interactable.

Single 

Allows the Interactable to only be focused by a single Interaction group at a time and allows other Interaction groups to take focus by automatically losing focus.

Multiple 

Allows for multiple Interaction groups at a time to focus the Interactable.

This option can be disabled in the Inspector window by adding the CanFocusMultipleAttribute with a value of false to a derived class of XRBaseInteractable.

Voir également
IXRSelectInteractable.selectMode
Valeurs énumérées
Single 

Allows the Interactable to only be selected by a single Interactor at a time and allows other Interactors to take selection by automatically deselecting.

Multiple 

Allows for multiple Interactors at a time to select the Interactable.

This option can be disabled in the Inspector window by adding the CanSelectMultipleAttribute with a value of false to a derived class of XRBaseInteractable.
