Description détaillée

Used by platform-specific OpenXR features to supply hand mesh data to XRHandSubsystem.

Only used by developers connecting an OpenXRFeature to XRHandSubsystem.TryGetMeshData. If you're a user making a game or app, you do not need to worry about this type.
