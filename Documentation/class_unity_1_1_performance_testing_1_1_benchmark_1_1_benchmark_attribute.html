Mark a class containing performance tests for use in benchmark comparison generation. Each variant defined in the enum Type will be ran and measured for comparison when running benchmarking. The variants in the enum also create mulitple appropriate Performance Test Framework tests for regression testing. See BenchmarkComparisonAttribute for more information on the enum definition. Description détaillée

Mark a class containing performance tests for use in benchmark comparison generation. Each variant defined in the enum Type will be ran and measured for comparison when running benchmarking. The variants in the enum also create mulitple appropriate Performance Test Framework tests for regression testing. See BenchmarkComparisonAttribute for more information on the enum definition.

Paramètres
