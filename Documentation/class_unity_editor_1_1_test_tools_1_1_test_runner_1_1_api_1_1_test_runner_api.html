Description détaillée

The TestRunnerApi retrieves and runs tests programmatically from code inside the project, or inside other packages. TestRunnerApi is a ScriptableObject. You can initialize the API like this:

var testRunnerApi = ScriptableObject.CreateInstance&lt;TestRunnerApi&gt;();
UnityEditor.TestTools.TestRunner.Api.TestRunnerApi
Definition TestRunnerApi.cs:29

Note: You can subscribe and receive test results in one instance of the API, even if the run starts from another instance. The TestRunnerApi supports the following workflows:

  • How to run tests programmatically
  • How to get test results
  • How to retrieve the list of tests

◆ CancelTestRun()

bool UnityEditor.TestTools.TestRunner.Api.TestRunnerApi.CancelTestRun ( string guid)
static

Cancel the test run with a given guid string. The guid string can be retrieved when executing the test run. The test run may take multiple frames to finish cleaning up from the test run. Any current active test will be marked as "Canceled" and any other remaining tests marked as "NotRun".

Paramètres
guidTest run guid string.
Renvoie
A boolean indicating whether canceling of the given job was successful. Canceling of a job will not be a success if no test job is found matching the guid, if the job is not currently or the job is already canceling.
