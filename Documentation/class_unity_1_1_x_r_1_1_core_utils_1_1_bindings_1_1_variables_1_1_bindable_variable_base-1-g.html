Propriétés

T Value [get, set]
 The internal variable value. When setting the value, subscribers may be notified. The subscribers will not be notified if this variable is initialized, is configured to check for equality, and the new value is equivalent.
int BindingCount [get]
 Get number of subscribed binding callbacks. Note that if you manually call Unsubscribe with the same callback several times this value may be inaccurate. For best results leverage the IEventBinding returned by the subscribe call and use that to unsubscribe as needed.
