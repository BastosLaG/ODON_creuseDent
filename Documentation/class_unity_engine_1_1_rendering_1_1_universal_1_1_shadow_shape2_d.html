Description détaillée

Class ShadowShape2D stores outline geometry for use with a shadow caster.

Documentation des énumérations membres

◆ OutlineTopology

enum UnityEngine.Rendering.Universal.ShadowShape2D.OutlineTopology

Used when calling SetShape to describe the supplied indicies.

Valeurs énumérées
Lines 

Describes an index array where a set of two consecutive points describes a line segment.

Triangles 

Describes an index array where a set of three consecutive points describes a triangle.

◆ WindingOrder

enum UnityEngine.Rendering.Universal.ShadowShape2D.WindingOrder

Used when calling SetShape to describe the winding direction of the supplied geometry.

Valeurs énumérées
Clockwise 

Describes an index array where all polygons have vertices in a clockwise order.

CounterClockwise 

Describes an index array where all polygons have vertices in a counterclockwise order.

SetShape creates shadow geometry using the supplied geometry.

Paramètres
verticesThe vertices used to create the shadow geometry.
indicesThe indices used to create the shadow geometry (Lines topology)
radiiThe radius at the vertex. Can be used to describe a capsule.
transformThe transform used to create the shadow geometry.
windingOrderThe winding order of the supplied geometry.
allowContractionSpecifies if the ShadowCaster2D is allowed to contract the supplied shape(s).
createInteriorGeometrySpecifies if the ShadowCaster2D should create interior geometry. Required for shadow casters that do not use renderers as their source.
