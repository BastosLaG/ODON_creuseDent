Description détaillée

Use this with your provider (if hand-tracking is enabled in your build settings) to have the subsystem automatically update. Users can subscribe to XRHandSubsystem.handsUpdated to respond to updates instead of waiting until a following update step. Makes use of UnityEngine.LowLevel.PlayerLoop to insert this automatic update at the beginning of the EarlyUpdate.XRUpdate loop.

If the Input System backend is enabled, this will also create and XRHandDevices which update themselves from the XRHandSubsystem.handsUpdated callback.
