Description détaillée

An interface that an XRTargetFilter can implement to receive calls whenever an Interactor links to or unlinks from its filter.
Implement this interface if the evaluator needs to subscribe to events or cache data from the linked Interactors.

◆ OnLink()

void UnityEngine.XR.Interaction.Toolkit.Filtering.IXRTargetEvaluatorLinkable.OnLink ( IXRInteractor interactor)

Called by the Target Filter when it links to the given Interactor. This is also called after the evaluator's XRTargetEvaluator.Awake for each already linked Interactor.
Use this only for code initialization for the given Interactor.

Paramètres
interactorThe Interactor being linked to the filter.

This is called even if the evaluator is disabled. You can check if the evaluator is enabled using the XRTargetEvaluator.enabled property.
You should not update the linked interactor list or the evaluator list in the filter, nor should you disable or enable evaluators. This can lead to out-of-order calls to OnLink and OnUnlink.
