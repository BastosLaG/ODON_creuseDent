Description détaillée

Low-level meshing data. If the call that retrieved this from XRHandSubsystem.TryGetMeshData was successful, XRHandMeshData.positions, XRHandMeshData.normals, and XRHandMeshData.uvs will all have the same length.

◆ Dispose()

void UnityEngine.XR.Hands.Meshing.XRHandMeshData.Dispose ( )

Dispose of array data in this object.

This method is idempotent, meaning it doesn't matter if it gets duplicate calls. Since XRHandMeshDataQueryResult's XRHandMeshDataQueryResult.Dispose calls this, that that means Dispose is safe to call on just XRHandMeshDataQueryResult.leftHand and XRHandMeshDataQueryResult.rightHand, just the containing XRHandMeshDataQueryResult, or both sets.

◆ TryGetRootPose()

bool UnityEngine.XR.Hands.Meshing.XRHandMeshData.TryGetRootPose ( out Pose rootPose)

Retrieves root pose, if this frame's data had one available.

Paramètres
rootPoseIf this function succeeds, this will be filled out with the root Pose for how the mesh data in this object is intended to be drawn. This pose should not be used otherwise.
Renvoie
Returns true if successful and the root pose was filled out, returns false otherwise.

If this function fails, you should continue to use the previous pose. If there has been no successful pose retrieval yet, the closest approximation would be the Pose of the wrist joint.
