Champs de données

float size
 Cascade normalized size that ranges from 0 to 1. Sum of all cascade sizes can not exceed 1.
float borderSize
 Cascade border size that ranges from 0 to 1. Border represents the width of shadow blend. Where 0 value result in no blend and 1 will blend from cascade beginning.
HandleState cascadeHandleState
 Current state of cascade handle that will be used for drawing it.
HandleState borderHandleState
 Current state of border handle that will be used for drawing it.
