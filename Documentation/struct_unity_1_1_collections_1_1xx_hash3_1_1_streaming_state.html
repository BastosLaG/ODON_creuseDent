Description détaillée

Type used to compute hash based on multiple data feed.

Allow to feed the internal hashing accumulators with data through multiple calls to Update, then retrieving the final hash value using DigestHash64 or DigestHash128. More info about how to use this class in its constructor.

Documentation des constructeurs et destructeur

◆ StreamingState()

Unity.Collections.xxHash3.StreamingState.StreamingState ( bool isHash64,
ulong seed = 0 )

Create a StreamingState object, ready to be used with the streaming API.

Paramètres
isHash64true if we are computing a 64bits hash value, false if we are computing a 128bits one
seedA seed value to be used to compute the hash, default is 0

Once the object is constructed, you can call the Update method as many times as you want to accumulate data to hash. When all the data has been sent, call DigestHash64 or DigestHash128 to retrieve the corresponding key, the StreamingState instance will then be reset, using the same hash key size and same Seed in order to be ready to be used again.
