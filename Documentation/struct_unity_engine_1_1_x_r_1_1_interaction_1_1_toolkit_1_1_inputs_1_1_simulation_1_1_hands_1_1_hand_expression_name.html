Description détaillée

A name for a hand expression in the XR Device Simulator. This struct wraps the InternedString struct from the Input System to allow for strings to be compared by reference for better performance. When compared, the strings are case-insensitive and culture-insensitive. When converting back to a string, the original casing will be preserved.
