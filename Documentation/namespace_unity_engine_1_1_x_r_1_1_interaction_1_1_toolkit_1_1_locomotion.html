enum UnityEngine.XR.Interaction.Toolkit.Locomotion.LocomotionState

The state of locomotion for any given LocomotionProvider.

Valeurs énumérées
Idle 

Locomotion state where the LocomotionProvider is idle, before locomotion input occurs.

Preparing 

Locomotion state where the LocomotionProvider is getting ready to move, when locomotion start input occurs.

The provider enters this state after calling LocomotionProvider.TryPrepareLocomotion. It remains in this state until it enters the Moving state, which happens either when the provider calls LocomotionProvider.TryStartLocomotionImmediately or during the LocomotionProvider.mediator's next LocomotionMediator.Update in which LocomotionProvider.canStartMoving is true, whichever happens first.

Moving 

Locomotion state where the LocomotionProvider is queuing IXRBodyTransformations with the XRBodyTransformer.

The provider can enter this state in one of two ways:

  1. From the Preparing state, the first time LocomotionProvider.canStartMoving is true during any of the LocomotionProvider.mediator's LocomotionMediator.Update calls after the provider called LocomotionProvider.TryPrepareLocomotion, or
  2. From any state other than Moving, immediately after the provider called LocomotionProvider.TryStartLocomotionImmediately.
Ended 

Locomotion state where the LocomotionProvider is no longer moving, after locomotion end input has completed.

The provider enters this state after calling LocomotionProvider.TryEndLocomotion, and it remains in this state until it returns to the Idle state during the LocomotionProvider.mediator's LocomotionMediator.Update in the next frame.
