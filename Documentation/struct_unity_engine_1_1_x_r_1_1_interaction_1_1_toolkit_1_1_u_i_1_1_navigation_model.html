Propriétés

Vector2 move [get, set]
 A 2D Vector that represents the up/down/left/right movement to apply to UI selection, such as moving up and down in options menus or highlighting options.
bool submitButtonDown [get, set]
 Tracks the current state of the submit or 'move forward' button. Setting this also updates the submitButtonDelta to track if a press or release occurred in the frame.
bool cancelButtonDown [get, set]
 Tracks the current state of the cancel or 'move backward' button. Setting this also updates the cancelButtonDelta to track if a press or release occurred in the frame.
