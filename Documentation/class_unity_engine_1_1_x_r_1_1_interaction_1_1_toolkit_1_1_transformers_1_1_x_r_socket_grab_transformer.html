void OnGrabCountChanged (XRGrabInteractable grabInteractable, Pose targetPose, Vector3 localScale)
 Called by Unity each time the number of selections changes for the given Interactable while grabbed by at least one Interactor, including when it is first grabbed. Use this to do any code initialization based on each Interactor currently selecting the Interactable, for example computing the initial distance between both Interactors grabbing the object.
Paramètres
grabInteractableThe XR Grab Interactable being grabbed.
targetPoseThe current target pose for the current frame.
localScaleThe current target scale of the Interactable's transform relative to the GameObject's parent.
There will always be at least one Interactor selecting the Interactable when this method is called. In other words, this will be called when the selection count changes from 0 to 1 and whenever it subsequently changes while still above 0. This method is called by Unity right before Process if the selection count changed.

Propriétés

bool canProcess = true [get, set]
 Whether this grab transformer can process targets. Transformers that can process targets receive calls to Process, transformers that cannot process do not. Transformers will still have other event methods called to allow for initialization on the frame the grab changes happens.
float socketSnappingRadius [get, set]
 When socket snapping is enabled, this is the radius within which the interactable will snap to the socket's attach transform while hovering.
SocketScaleMode scaleMode [get, set]
 Scale mode used to calculate the scale factor applied to the interactable when hovering.
float3 fixedScale = new float3(1f, 1f, 1f) [get, set]
 Scale factor applied to the interactable when scale mode is set to Fixed.
float3 targetBoundsSize = new float3(1f, 1f, 1f) [get, set]
 Bounds size used to calculate the scale factor applied to the interactable when scale mode is set to Stretched To Fit Size.
IXRInteractor socketInteractor [get, set]
 The current socket interactor.

Description détaillée

Transformer used when an interactable is snapped to a socket. Applies both when select is active and when hover socket snapping is active.

void UnityEngine.XR.Interaction.Toolkit.Transformers.XRSocketGrabTransformer.OnGrabCountChanged ( XRGrabInteractable grabInteractable,
Pose targetPose,
Vector3 localScale )

Called by Unity each time the number of selections changes for the given Interactable while grabbed by at least one Interactor, including when it is first grabbed. Use this to do any code initialization based on each Interactor currently selecting the Interactable, for example computing the initial distance between both Interactors grabbing the object.

Paramètres
grabInteractableThe XR Grab Interactable being grabbed.
targetPoseThe current target pose for the current frame.
localScaleThe current target scale of the Interactable's transform relative to the GameObject's parent.
There will always be at least one Interactor selecting the Interactable when this method is called. In other words, this will be called when the selection count changes from 0 to 1 and whenever it subsequently changes while still above 0. This method is called by Unity right before Process if the selection count changed.
