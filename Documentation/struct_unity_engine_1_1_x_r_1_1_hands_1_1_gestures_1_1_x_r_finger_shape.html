Description détaillée

The calculated state of certain relative geometric properties of a finger from a given hand. Useful for pose detection. All values are normalized from 0 to 1.

Do not construct this yourself. Only retrieve it from XRFingerShapeMath.CalculateFingerShape(XRHand, XRHandFingerID, XRFingerShapeTypes) or XRFingerShapeMath.CalculateFingerShape(XRHand, XRHandFingerID, XRFingerShapeTypes, XRFingerShapeConfiguration).
