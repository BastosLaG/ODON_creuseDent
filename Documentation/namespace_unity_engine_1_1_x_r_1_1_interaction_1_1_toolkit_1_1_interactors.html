◆ ScaleMode

enum UnityEngine.XR.Interaction.Toolkit.Interactors.ScaleMode

Enum representing the two modes of scaling: ScaleOverTime and DistanceDelta.

Voir également
IXRScaleValueProvider.scaleMode, XRRayInteractor.scaleMode
Valeurs énumérées
None 

No scale mode is active or supported. Use this when a controller does not support scaling or when scaling is not needed.

ScaleOverTime 

Scale over time mode: The scale is resized over time and represented by input in range of -1 to 1. This mode is typically used with a thumbstick input on a controller.

Input 

(Deprecated) Use ScaleOverTime instead.

DistanceDelta 

Distance scale mode: The scale is based on the delta distance between 2 physical (or virtual) inputs, such as the pinch gap between fingers where the distance is calculated based on the screen DPI, and delta from the previous frame. This mode is typically used with a touchscreen for mobile AR.

Distance 

(Deprecated) Use DistanceDelta instead.

◆ SocketScaleMode

enum UnityEngine.XR.Interaction.Toolkit.Interactors.SocketScaleMode

Enum used to determine how the socket should scale the interactable.

Voir également
XRSocketInteractor.socketScaleMode
Valeurs énumérées
None 

The interactable will not be scaled when attached to the socket.

Fixed 

The interactable will be scaled to a fixed size when attached to the socket. The actual size is defined by the XRSocketInteractor.fixedScale value.

StretchedToFitSize 

The interactable will be scaled to fit the size of the socket when attached. The scaling is dynamic, computed using the interactable's bounds, with a target size defined by XRSocketInteractor.targetBoundsSize.

◆ TargetPriorityMode

enum UnityEngine.XR.Interaction.Toolkit.Interactors.TargetPriorityMode

Options for how many Targets (or Interactables with priority for selection) to monitor.

The options are in order of best performance.

Voir également
IXRTargetPriorityInteractor
Valeurs énumérées
None 

Monitors no Target, the IXRTargetPriorityInteractor.targetsForSelection list will not be updated. This option has very low performance cost.

HighestPriorityOnly 

Only monitors the highest priority Target, the IXRTargetPriorityInteractor.targetsForSelection list will only be updated with the highest priority Target, or it'll be empty if there is no Target that can be selected in the current frame. This option has moderate performance cost.

All 

Tracks all Targets, the IXRTargetPriorityInteractor.targetsForSelection list will be updated with all Interactables that can be selected in the current frame. This option has high performance cost.
