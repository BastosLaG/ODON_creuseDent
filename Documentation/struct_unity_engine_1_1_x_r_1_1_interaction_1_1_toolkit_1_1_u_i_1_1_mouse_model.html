bool UnityEngine.XR.Interaction.Toolkit.UI.MouseModel.changedThisFrame
get

A boolean value representing whether any mouse data has changed this frame, meaning that events should be processed.

This only checks for changes in mouse state (position, leftButton, rightButton, middleButton, or scrollDelta).
