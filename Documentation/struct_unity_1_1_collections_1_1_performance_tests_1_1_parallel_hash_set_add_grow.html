◆ AllocBclContainer()

object Unity.Collections.PerformanceTests.ParallelHashSetAddGrow.AllocBclContainer ( int capacity)

Called during setup for each measurement in a sample set with the capacity to allocate to the managed container when the benchmark type is BenchmarkContainerConfig.BCL.

This is also called during teardown for each measurement in a sample set with '-1' to indicate freeing the container.

Paramètres
capacityThe capacity to allocate for the managed container. Capacity of 0 will still create a container, but it will be empty. A capacity of -1 will dispose the container and free associated allocation(s).
Renvoie
A reference to the allocated container when capacity >= 0, and null when capacity < 0.
