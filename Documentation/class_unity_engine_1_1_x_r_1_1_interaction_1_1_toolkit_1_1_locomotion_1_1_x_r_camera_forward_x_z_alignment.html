Description détaillée

Transformation that rotates the target's XRMovableBody.originTransform about the axis aligned with the Origin's up vector and passing through the world position of the XROrigin.Camera, such that the projection of the camera's forward vector onto the Origin's XZ plane matches the projection of the specified vector onto the Origin's XZ plane.
