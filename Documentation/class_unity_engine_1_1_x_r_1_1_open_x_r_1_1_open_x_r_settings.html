◆ ColorSubmissionModeGroup

enum UnityEngine.XR.OpenXR.OpenXRSettings.ColorSubmissionModeGroup

Runtime color format - keep in sync with NativePlugin\Source\unity_types.h.

Valeurs énumérées
kRenderTextureFormatGroup8888 

Color render texture format, 8 bits per channel. This is the default swapchain format. Analogous to kUnityXRRenderTextureFormatRGBA32/BGRA32, auto-selecting the preferred color order for the platform.

kRenderTextureFormatGroup1010102_Float 

Color render texture format. 10 bits for colors, 2 bits for alpha. Analogous to kUnityXRRenderTextureFormatRGBA1010102/BGRA1010102, auto-selecting the preferred color order for the platform.

kRenderTextureFormatGroup16161616_Float 

Color render texture format, 16 bit floating point per channel, auto-selecting the preferred color order for the platform.

kRenderTextureFormatGroup565 

Color render texture format. 5 bits for Red channel, 6 bits for Green channel, 5 bits for Blue channel, auto-selecting the preferred color order for the platform.

kRenderTextureFormatGroup111110_Float 

Color render texture format. R and G channels are 11 bit floating point, B channel is 10 bit floating point.

◆ RefreshRecenterSpace()

void UnityEngine.XR.OpenXR.OpenXRSettings.RefreshRecenterSpace ( )
static

Regenerates the internal XR space used for recentering, updating the tracking origin to the most recent floor-based position from the runtime.

This method needs that AllowRecentering is turned on using SetAllowRecentering, otherwise it will do nothing.

This method doesn't trigger a recenter event, as this event has to be initiated from the platform's runtime.

See SetAllowRecentering for more information.

◆ SetAllowRecentering()

void UnityEngine.XR.OpenXR.OpenXRSettings.SetAllowRecentering ( bool allowRecentering,
float floorOffset = 1::5f )
static

Activates reference space recentering when using floor-based tracking origin.

When a recentering event is performed, OpenXR will attempt to recenter the world space origin based on the local-floor reference space, if supported by the platform's hardware.

If that reference space isn't supported, OpenXR will then attempt to approximate it using stage space or local space.

Calling this method won't trigger a recenter event. This event will be sent from the platform's runtime.

Paramètres
allowRecenteringBoolean value that activates the recentering feature.
floorOffsetEstimated height used when approximating the floor-based position when recentering the space. By default, this value is 1.5f
