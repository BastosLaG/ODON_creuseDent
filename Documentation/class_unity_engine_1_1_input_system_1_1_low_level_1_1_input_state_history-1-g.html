Description détaillée

Records value changes of a given control over time.

Paramètres du template
TValueThe type of the record being stored

This class makes it easy to track input values over time. It will automatically retain input state up to a given maximum history depth (InputStateHistory.historyDepth). When the history is full, it will start overwriting the oldest entry each time a new history record is received.

The class listens to changes on the given controls by adding change monitors (IInputStateChangeMonitor) to each control.
