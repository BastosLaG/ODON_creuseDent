Description détaillée

Use this attribute to add a menu item to a context menu. Used to indicate path and priority that are auto added to the menu (examples can be found on ).

Unlike Menu item, MenuEntryAttribute doesn't handle shortcuts in the menu name. See TimelineShortcutAttribute.

UnityEditor.Timeline.Actions.MenuEntryAttribute.MenuEntryAttribute ( string path = default,
int priority = MenuPriority::defaultPriority )

Constructor for Menu Entry Attribute to define information about the menu item for an action.

Paramètres
pathPath to the menu. If there is a "/" in the path, it will create one (or multiple) submenu items.
priorityPriority to decide where the menu will be positioned in the menu. The lower the priority, the higher the menu item will be in the context menu.
