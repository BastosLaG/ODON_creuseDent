Graphe d'héritage de UnityEngine.XR.Interaction.Toolkit.Inputs.Readers.IXRInputValueReader:

Description détaillée

Base interface for all input value readers.

This empty interface is needed to allow the RequireInterface attribute to be used. Generic attributes aren't supported until C# 11, so we can't use a typed interface with the RequireInterface attribute yet.
