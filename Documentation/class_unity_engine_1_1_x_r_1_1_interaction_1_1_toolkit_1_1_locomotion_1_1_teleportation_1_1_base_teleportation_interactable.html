◆ SendTeleportRequest()

bool UnityEngine.XR.Interaction.Toolkit.Locomotion.Teleportation.BaseTeleportationInteractable.SendTeleportRequest ( IXRInteractor interactor)
protected

Queues a request to teleport. This method can be called from script to initiate teleportation manually rather than relying on the interaction system to initiate teleportation.

Paramètres
interactorThe interactor, if any, that initiated the teleport trigger. If null, the teleport request will be generated without a raycast hit.
Renvoie
Returns true if successfully queued. Otherwise, returns false.

Due to script execution order of the TeleportationProvider, depending on when this method is called, teleportation of the XR Origin may not occur until the next frame.

◆ matchOrientation

MatchOrientation UnityEngine.XR.Interaction.Toolkit.Locomotion.Teleportation.BaseTeleportationInteractable.matchOrientation
getset

How to orient the rig after teleportation.

Set to:

  • MatchOrientation.WorldSpaceUp to stay oriented according to the world space up vector.
  • MatchOrientation.TargetUp to orient according to the target BaseTeleportationInteractable Transform's up vector.
  • MatchOrientation.TargetUpAndForward to orient according to the target BaseTeleportationInteractable Transform's rotation.
  • MatchOrientation.None to maintain the same orientation before and after teleporting.
