Propriétés

bool stripUnusedPostProcessingVariants [get, set]
 Controls whether to automatically strip post processing shader variants based on VolumeProfile components. Stripping is done based on VolumeProfiles in project, their usage in scenes is not considered.
bool stripUnusedVariants [get, set]
 Controls whether to strip variants if the feature is disabled.
bool stripScreenCoordOverrideVariants [get, set]
 Controls whether Screen Coordinates Override shader variants are automatically stripped.
