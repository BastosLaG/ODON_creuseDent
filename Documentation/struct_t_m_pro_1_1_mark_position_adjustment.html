Référence de la structure TMPro.MarkPositionAdjustment

A MarkPositionAdjustment defines the positional adjustment of a glyph relative to the anchor point of base glyph. This data structure is used by the Mark-to-Base, Mark-to-Mark and Mark-to-Ligature OpenType font features. Plus de détails...

Description détaillée

A MarkPositionAdjustment defines the positional adjustment of a glyph relative to the anchor point of base glyph. This data structure is used by the Mark-to-Base, Mark-to-Mark and Mark-to-Ligature OpenType font features.
