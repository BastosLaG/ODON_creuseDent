static

Linearly interpolates between two gradients with options to independently skip color or alpha interpolation.

Paramètres
aThe first gradient.
bThe second gradient.
tInterpolation factor (0 to 1).
lerpColorsIf true, interpolate colors; otherwise, use colors from gradient b.
lerpAlphasIf true, interpolate alphas; otherwise, use alphas from gradient b.
Renvoie
Returns the interpolated gradient as a new gradient instance.

This method allocates a new Gradient instance for the interpolated result. Consider using the other Lerp method to provide a pre-allocated Gradient instance to avoid GC allocations.
