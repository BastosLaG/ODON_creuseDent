Description détaillée

Wraps a list or array to provide a read-only view of some or all elements. Elements are not copied, so if the underlying collection changes, the ReadOnlyListSpan will see the updated elements.

It is preferable to use this collection in API designs instead of IReadOnlyCollection because GetEnumerator returns a value-type enumerator and does not perform any heap allocations.

This collection is not thread-safe.

Paramètres du template
TThe element type.
