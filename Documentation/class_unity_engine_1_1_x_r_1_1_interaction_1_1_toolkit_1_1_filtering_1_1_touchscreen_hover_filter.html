Référence de la classe UnityEngine.XR.Interaction.Toolkit.Filtering.TouchscreenHoverFilter

Hover filter that checks if the screen is being touched and doing a selecting gesture. Can be used with the ray interactor to prevent hover interactions when the screen is not being touched. Plus de détails...

Graphe d'héritage de UnityEngine.XR.Interaction.Toolkit.Filtering.TouchscreenHoverFilter:

Fonctions membres publiques

bool Process (IXRHoverInteractor interactor, IXRHoverInteractable interactable)
 Called by the host object (XRInteractionManager, XRBaseInteractor or XRBaseInteractable) to verify if the hover interaction between the given Interactor and Interactable can be performed.
Paramètres
interactorThe Interactor to validate the hover interaction.
interactableThe Interactable to validate the hover interaction.
Renvoie
Returns true when the given Interactor can hover the given Interactable. Otherwise, returns false.

Description détaillée

Hover filter that checks if the screen is being touched and doing a selecting gesture. Can be used with the ray interactor to prevent hover interactions when the screen is not being touched.
