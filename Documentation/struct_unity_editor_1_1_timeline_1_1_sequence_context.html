Description détaillée

A context for the Timeline window (RO)

The SequenceContext represents a state of the Timeline window, and is used to interact with TimelineNavigator.

Documentation des constructeurs et destructeur

◆ SequenceContext()

UnityEditor.Timeline.SequenceContext.SequenceContext ( PlayableDirector director,
TimelineClip clip )

Initializes and returns an instance of SequenceContext.

Paramètres
directorThe PlayableDirector associated with the context. Must be a valid PlayableDirector reference.
clipThe TimelineClip reference that controls the sequence. Specify null to specify that the sequence is the root. If non-null, the clip must be part of a valid TimelineAsset.
Exceptions
System.ArgumentNullExceptiondirector is null.
System.ArgumentExceptionThe clip is not part of a TrackAsset.
System.ArgumentExceptionThe clip is part of a track but not part of a TimelineAsset.
