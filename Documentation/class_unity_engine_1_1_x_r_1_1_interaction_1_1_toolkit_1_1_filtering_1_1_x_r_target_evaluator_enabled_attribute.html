Graphe d'héritage de UnityEngine.XR.Interaction.Toolkit.Filtering.XRTargetEvaluatorEnabledAttribute:

Description détaillée

Attribute used to mark the m_Enabled serialized field of XR Target Evaluators to allow its XRTargetEvaluator.OnEnable and XRTargetEvaluator.OnDisable methods to be invoked at runtime when toggled in the Inspector window.
