Description détaillée

RecompileScripts is an IEditModeTestYieldInstruction that you can yield in Edit Mode tests. It lets you trigger a recompilation of scripts in the Unity Editor.

Paramètres
expectScriptCompilationThis parameter indicates if you expect a script compilation to start (defaults to true). If a script compilation does not start and expectScriptCompilation is true, then it throws an exception.

UnityEngine.TestTools.RecompileScripts.RecompileScripts ( bool expectScriptCompilation,
bool expectScriptCompilationSuccess )

Creates a new instance of the RecompileScripts yield instruction.

Paramètres
expectScriptCompilationThis parameter indicates if you expect a script compilation to start (defaults to true). If a script compilation does not start and expectScriptCompilation is true, then it throws an exception.
expectScriptCompilationSuccessThis parameter indicates if you expect a script compilation to succeed. If not succeeded then an exception will be thrown.
