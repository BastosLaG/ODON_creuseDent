Documentation du type de l'énumération

◆ DisplayCondition

enum Unity.Multiplayer.Center.Common.DisplayCondition

A condition for a section to be displayed.

Valeurs énumérées
None 

As long as the type exists in the project, the section is shown. Exception: a section with a higher priority is defined for the same id.

PackageInstalled 

A target package is defined in TargetPackageId and the package is installed If multiple types share the same id, the one with the highest priority is shown.

NoPackageInstalled 

Shown if no multiplayer package is installed (e.g. for the first time user that has not installed anything) Check SectionsFinder.k_TargetPackages to see which packages are checked.

◆ InfrastructureDependency

enum Unity.Multiplayer.Center.Common.InfrastructureDependency

Defines if a section depends on a certain hosting model.

Valeurs énumérées
None 

No dependency, the section is shown if all other conditions are also met.

ClientHosted 

Only available when the user has selected a client hosted infrastructure.

DedicatedServer 

Only available when the user has selected a dedicated server infrastructure.

CloudCode 

Only available when the user has selected Cloud Code as their hosting model.

◆ OnboardingSectionCategory

enum Unity.Multiplayer.Center.Common.OnboardingSectionCategory

The UI category the section will fall into.

Valeurs énumérées
Intro 

Comes at the top and should cover overarching topics for beginners.

Netcode 

Section about the fundamentals of gameplay synchronization implementation and debugging. This includes netcode and tools related to netcode, as well as alternative solutions.

ConnectingPlayers 

Section gathering information about connecting players together, such as lobbies, voice chat, matchmaking and widgets.

ServerInfrastructure 

Section gathering information about deploying, running and optimizing a game server.

Other 

Something else.

LiveOps 

LiveOps sections which are meant to be used after some development happened on the game.
