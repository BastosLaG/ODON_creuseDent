List< Transform > anchorTransforms [get]

TeleportVolumeDestinationSettingsDatumProperty destinationEvaluationSettings [get, set]
 Settings for how this volume evaluates a destination anchor.
ITeleportationVolumeAnchorFilter destinationEvaluationFilter [get]
 The filter used to evaluate a teleportation destination from the list of anchors. This is the same as the TeleportVolumeDestinationSettings.destinationEvaluationFilter in destinationEvaluationSettings unless that value is null, in which case this will return an instance of FurthestTeleportationAnchorFilter.
float destinationEvaluationProgress [get]
 A normalized representation of the current progress towards evaluating a destination anchor, depending on destinationEvaluationSettings. This value is 0 while not hovered. If TeleportVolumeDestinationSettings.enableDestinationEvaluationDelay is true, this value will start at 0 when initiating destination evaluation (either upon first hover or when re-evaluation occurs due to TeleportVolumeDestinationSettings.pollForDestinationChange) and will increase to 1 over the course of TeleportVolumeDestinationSettings.destinationEvaluationDelayTime seconds while hovered. Otherwise, this value will be 1 while hovered. This resets to 0 after the volume creates a teleport request.
Transform destinationAnchor [get]
 The transform representing the current teleportation destination. When destinationEvaluationProgress is 1, this will be one of the transforms in anchorTransforms. Otherwise, this will be null.
