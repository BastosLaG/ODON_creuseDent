Référence de la classe UnityEngine.XR.Interaction.Toolkit.Interactors.XRDirectInteractor

Interactor used for directly interacting with interactables that are touching. This is handled via trigger volumes that update the current set of valid targets for this interactor. This component must have a collision volume that is set to be a trigger to work. Plus de détails...

Description détaillée

Interactor used for directly interacting with interactables that are touching. This is handled via trigger volumes that update the current set of valid targets for this interactor. This component must have a collision volume that is set to be a trigger to work.

◆ improveAccuracyWithSphereCollider

bool UnityEngine.XR.Interaction.Toolkit.Interactors.XRDirectInteractor.improveAccuracyWithSphereCollider
getset

When a Sphere Collider component is the only collider on this interactor, and no Rigidbody component is attached, the interactor will use Burst compiler optimizations and sphere casts instead of relying on physics trigger events to evaluate direct interactions when this property is enabled. This also improves inter-frame accuracy and reliability.

Cannot change this value at runtime after Awake. Enabling this property can improve inter-frame reliability during fast motion when the requirements for optimization are met by running on each Update instead of Fixed Update and using a sphere cast to determine valid targets. Disable to force the use of trigger events, such as the OnTriggerStay and FixedUpdate methods.

◆ physicsTriggerInteraction

QueryTriggerInteraction UnityEngine.XR.Interaction.Toolkit.Interactors.XRDirectInteractor.physicsTriggerInteraction
getset

Determines whether the direct interactor sphere overlap will hit triggers when using the improveAccuracyWithSphereCollider option.

When set to QueryTriggerInteraction.UseGlobal, the value of Queries Hit Triggers (Physics.queriesHitTriggers) in Edit > Project Settings > Physics will be used.
