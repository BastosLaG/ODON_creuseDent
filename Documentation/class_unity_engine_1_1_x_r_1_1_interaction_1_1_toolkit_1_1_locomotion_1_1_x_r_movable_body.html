◆ LinkConstrainedManipulator()

void UnityEngine.XR.Interaction.Toolkit.Locomotion.XRMovableBody.LinkConstrainedManipulator ( IConstrainedXRBodyManipulator manipulator)

Links the given constrained manipulator to this body. This sets constrainedManipulator to manipulator and calls IConstrainedXRBodyManipulator.OnLinkedToBody on the manipulator.

Paramètres
manipulatorThe constrained manipulator to link.

If constrainedManipulator is already not null when this is called, this first calls IConstrainedXRBodyManipulator.OnUnlinkedFromBody on constrainedManipulator. Also, if the given manipulator already has a IConstrainedXRBodyManipulator.linkedBody set, this calls UnlinkConstrainedManipulator on that body.
