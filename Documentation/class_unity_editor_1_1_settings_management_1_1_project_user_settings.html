Represents a settings repository that stores data local to a Unity project. The settings data is serialized to a JSON file.

UnityEditor.SettingsManagement.ProjectUserSettings.ProjectUserSettings ( string package,
string name = "Settings" )

Initializes and returns an instance of the ProjectUserSettings repository with the serialized data location set to a path defined by the specified package and name values relative to the UserSettings directory. For example: MyUnityProject/UserSettings/Packages/com.example.my-package/Settings.json.

Paramètres
packageThe name of the package to store the serialized data under.
nameThe base filename to use for the serialized data location (defaults to "Settings").
