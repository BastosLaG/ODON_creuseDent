Description détaillée

A condition that can be used to check the orientation of a hand relative to some other target. The target is another transform referenced by the target property.

To check the orientation relative to the user's head or origin, use UserOrientation to avoid the need to set a specific target transform per condition.

Documentation des propriétés

◆ angleTolerance

float UnityEngine.XR.Hands.Gestures.XRHandRelativeOrientation.TargetCondition.angleTolerance
getset

If the alignmentCondition is XRHandAlignmentCondition.AlignsWith, this is the maximum angle between the handAxis and the reference direction for the condition to be met.

If the alignmentCondition is XRHandAlignmentCondition.OppositeTo, this is the maximum angle between the handAxis and the opposite of the reference direction for the condition to be met.

If the alignmentCondition is XRHandAlignmentCondition.PerpendicularTo, this is the maximum angle difference from 90 degrees (perpendicular) between the handAxis and the reference direction for the condition to be met.
