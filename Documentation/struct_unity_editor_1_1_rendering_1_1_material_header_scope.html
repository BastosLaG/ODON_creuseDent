Description détaillée

Create a toggleable header for material UI, must be used within a scope.

void OnGUI()
{
using (var header = new MaterialHeaderScope(text, ExpandBit, editor))
{
if (header.expanded)
EditorGUILayout.LabelField("Hello World !");
}
}

Creates a material header scope to display the foldout in the material UI.

Paramètres
titleGUI Content of the header.
bitExpandedBit index which specifies the state of the header (whether it is open or collapsed) inside Editor Prefs.
materialEditorThe current material editor.
spaceAtEndSet this to true to make the block include space at the bottom of its UI. Set to false to not include any space.
subHeaderSet to true to make this into a sub-header. This affects the style of the header. Set to false to make this use the standard style.
defaultExpandedStateThe default state if the header is not present
documentationURL[optional] Documentation page
