UnityEditor.Rendering.ExpandedState< TState, TTarget >.ExpandedState ( TState defaultValue,
string prefix = "CoreRP",
string stateId = "UI_State" )

Constructor will create the key to store in the EditorPref the state given generic type passed. The key will be formated as such prefix:TTarget:TState:UI_State.

Paramètres
defaultValueIf key did not exist, it will be created with this value for initialization.
prefix[Optional] Prefix scope of the key (Default is CoreRP)
stateId[Optional] Postfix used to differentiate between different keys (Default is UI_State)
