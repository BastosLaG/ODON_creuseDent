Get the reticle direction based on the given interactor's attach transform.

Paramètres
interactorThe interactor whose attach transform determines the reticle direction.
hitNormalThe normal of the surface the reticle is placed on. This is the default value for reticleUp if the provider does not specify up directionality.
reticleUpThe returned up direction of the reticle.
optionalReticleForwardThe returned forward direction which will be projected onto the plane defined by reticleUp to determine the reticle's actual forward direction. This will be null if the provider does not specify forward directionality.
