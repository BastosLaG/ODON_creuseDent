Propriétés

bool overrideGazeTimeToSelect [get]
 Enables this interactable to override the XRRayInteractor.hoverTimeToSelect on a XRGazeInteractor.
float gazeTimeToSelect [get]
 Number of seconds for which an XRGazeInteractor must hover over this interactable to select it if XRRayInteractor.hoverToSelect is enabled.
bool overrideTimeToAutoDeselectGaze [get]
 Enables this interactable to override the XRRayInteractor.timeToAutoDeselect on a XRGazeInteractor.
float timeToAutoDeselectGaze [get]
 Number of seconds that the interactable will remain selected by a XRGazeInteractor before being automatically deselected if overrideTimeToAutoDeselectGaze is true.
