Description détaillée

Base class for input controls with a specific value type.

Paramètres du template
TValueType of value captured by the control. Note that this does not mean that the control has to store data in the given value format. A control that captures float values, for example, may be stored in state as byte values instead.

◆ ReadValue()

TValue UnityEngine.InputSystem.InputControl< TValue >.ReadValue ( )

Returns the current value of the control after processors have been applied.

Renvoie
The controls current value.

This can only be called on devices that have been added to the system (InputDevice.added).

If internal feature "USE_READ_VALUE_CACHING" is enabled, then this property implements caching to avoid applying processors when the underlying control has not changed. With this in mind, be aware of processors that use global state, such as the Processors.AxisDeadzoneProcessor. Unless the control unprocessed value has been changed, input system settings changed or InputControl.ApplyParameterChanges() invoked, the processors will not run and calls to value will return the same result as previous calls.

If a processor requires to be run on every read, override InputProcessor.cachingPolicy property in the processor and set it to InputProcessor.CachingPolicy.EvaluateOnEveryRead.

To improve debugging try setting "PARANOID_READ_VALUE_CACHING_CHECKS" internal feature flag to check if cache value is still consistent. https://docs.microsoft.com/en-us/dotnet/csharp/write-safe-efficient-code#avoid-defensive-copies.
