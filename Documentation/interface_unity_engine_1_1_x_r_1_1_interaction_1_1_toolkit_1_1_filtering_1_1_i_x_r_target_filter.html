Description détaillée

An interface responsible to filter a list of Interactable targets (candidates) for interaction with a linked Interactor.

An Interactor and an implementation of this interface are linked when a call to Link happens and they are unlinked when a call to Unlink happens. A linked Interactor can forward its Interactable target filtering logic to this interface implementation by calling Process.
An XRBaseInteractor and a Target Filter can be linked when an implementation of this interface is assigned to XRBaseInteractor.targetFilter.
It's possible to have multiple Interactors linked to the same Target Filter.

Called by the linked Interactor to filter the Interactables that it could possibly interact with this frame. Implement your custom logic to filter the Interactable candidates in this method.

Paramètres
interactorThe linked Interactor whose Interactable candidates (or targets) are being filtered.
targetsThe read only list of candidate Interactables to filter. This list should not be modified.
resultsThe results list to populate with the filtered results. This list should be sorted by priority (with highest priority first).

It's recommended to call this from an implementation of IXRInteractor.GetValidTargets.
