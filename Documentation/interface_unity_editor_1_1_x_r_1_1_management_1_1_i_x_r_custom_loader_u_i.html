Description détaillée

Custom interface provided by the package if the package uses its own UI in the XR Plug-in Management loader selection window.

Any class that implements this interface must be tagged with the XRCustomLoaderUIAttribute attribute.

◆ RequiredRenderHeight

float UnityEditor.XR.Management.IXRCustomLoaderUI.RequiredRenderHeight
get

The height of the area within the UI that this renderer will need to render its UI. This height will be the height of the rect passed into the OnGUI call. This should return a a non-zero value that's a multiple of the line height set in SetRenderedLineHeight.

Non-zero multiple of the line height set in SetRenderedLineHeight. If this is 0, the rect passed to OnGUI will be the default line height.
