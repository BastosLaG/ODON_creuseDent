float duration )

Sends a haptic impulse on the configured channel or default channel of the configured device.

Paramètres
amplitudeThe desired motor amplitude that should be within a [0-1] range.
durationThe desired duration of the impulse in seconds.
Renvoie
Returns true if successful. Otherwise, returns false.

This method considers sending the haptic impulse a success (and thus returns true) if the haptic impulse was successfully sent to the device even if frequency is ignored or not supported by the device.
Uses the default frequency of the device.

◆ SendHapticImpulse() [2/2]

bool UnityEngine.XR.Interaction.Toolkit.Inputs.Haptics.HapticImpulsePlayer.SendHapticImpulse ( float amplitude,
float duration,
float frequency )

Sends a haptic impulse on the configured channel or default channel of the configured device.

Paramètres
amplitudeThe desired motor amplitude that should be within a [0-1] range.
durationThe desired duration of the impulse in seconds.
frequencyThe desired frequency of the impulse in Hz. A value of 0 means to use the default frequency of the device.
Renvoie
Returns true if successful. Otherwise, returns false.

This method considers sending the haptic impulse a success (and thus returns true) if the haptic impulse was successfully sent to the device even if frequency is ignored or not supported by the device.
Frequency is currently only functional when the OpenXR Plugin (com.unity.xr.openxr) package is installed and the input action is using an input binding to a Haptic Control.
