bool UnityEngine.EventSystems.PhysicsRaycaster.ComputeRayAndDistance ( PointerEventData eventData,
ref Ray ray,
ref int eventDisplayIndex,
ref float distanceToClipPlane )
protected

Returns a ray going from camera through the event position and the distance between the near and far clipping planes along that ray.

Paramètres
eventDataThe pointer event for which we will cast a ray.
rayThe ray to use.
eventDisplayIndexThe display index used.
distanceToClipPlaneThe distance between the near and far clipping planes along the ray.
Renvoie
True if the operation was successful. false if it was not possible to compute, such as the eventPosition being outside of the view.

◆ maxRayIntersections

int UnityEngine.EventSystems.PhysicsRaycaster.maxRayIntersections
getset

Max number of ray intersection allowed to be found.

A value of zero will represent using the allocating version of the raycast function where as any other value will use the non allocating version.
