Propriétés

bool AutoReferenced = true [get, set]
 Gets or sets a value indicating whether the assemblies (*.dll files) of this NuGet package should be automatically referenced. Assemblies with this setting are automatically referenced by the sup projects generated by Unity. When this setting is set to false the assemblies of this NuGet package are only referenced by Unity projects that explicitly list them inside there *.asmdef file.
string TargetFramework [get, set]
 Gets or sets the configured target framework moniker that is used to install this NuGet package instead of automatically determining the best matching target framework from the Unity settings ('Api Compatibility Level').
