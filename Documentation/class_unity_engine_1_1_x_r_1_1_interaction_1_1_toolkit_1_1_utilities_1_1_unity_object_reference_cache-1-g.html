bool TryGet (T field, out T fieldOrNull)
 A fast but unsafe method for getting the field without doing a Unity Object alive check after the first time. The purpose is to avoid the overhead of the Unity Object alive check when it is known that the reference is alive, but does not have the rigor of detecting when the Object is deleted or destroyed after the first check, which should be very rare. This will handle the user modifying the field in the Inspector window by invalidating the cached version.

bool UnityEngine.XR.Interaction.Toolkit.Utilities.UnityObjectReferenceCache< T >.TryGet ( T field,
out T fieldOrNull )

A fast but unsafe method for getting the field without doing a Unity Object alive check after the first time. The purpose is to avoid the overhead of the Unity Object alive check when it is known that the reference is alive, but does not have the rigor of detecting when the Object is deleted or destroyed after the first check, which should be very rare. This will handle the user modifying the field in the Inspector window by invalidating the cached version.

Paramètres
fieldThe serialized field to get.
fieldOrNullThe Unity Object or actual null.
Renvoie
Returns true if the reference is not null. Otherwise, returns false.
