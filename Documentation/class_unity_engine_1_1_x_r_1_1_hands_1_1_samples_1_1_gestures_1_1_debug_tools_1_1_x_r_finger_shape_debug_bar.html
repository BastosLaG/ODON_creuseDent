 The container that determines the width of the max length bar, and holds the target and range indicators.
Transform valueBar [get, set]
 The bar that displays the value by being scaled in its local x axis from 0 to 1.
RectTransform targetIndicator [get, set]
 The RectTransform that displays the target value by being positioned in its anchored x position from 0 to the barContainer width.
RectTransform upperRangeIndicator [get, set]
 The RectTransform that displays the upper range by being positioned in its anchored x position from the range center and with the width of the range, proportional to the barContainer.
RectTransform lowerRangeIndicator [get, set]
 The RectTransform that displays the lower range by being positioned in its anchored x position from the range center and with the width of the range, proportional to the barContainer.
