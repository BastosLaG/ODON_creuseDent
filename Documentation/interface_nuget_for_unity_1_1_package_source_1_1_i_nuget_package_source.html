◆ SearchAsync()

Task< List< INugetPackage > > NugetForUnity.PackageSource.INugetPackageSource.SearchAsync ( string searchTerm = "",
bool includePrerelease = false,
int numberToGet = 15,
int numberToSkip = 0,
CancellationToken cancellationToken = default )

Gets a list of NugetPackages from this package source. This allows searching for partial IDs or even the empty string (the default) to list ALL packages.

Paramètres
searchTermThe search term to use to filter packages. Defaults to the empty string.
includePrereleaseTrue to include prerelease packages (alpha, beta, etc).
numberToGetThe number of packages to fetch.
numberToSkipThe number of packages to skip before fetching.
cancellationTokenToken that can be used to cancel the asynchronous task.
Renvoie
The list of available packages.
