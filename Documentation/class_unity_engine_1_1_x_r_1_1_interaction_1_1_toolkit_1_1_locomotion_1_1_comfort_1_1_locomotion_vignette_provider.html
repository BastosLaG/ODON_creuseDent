Graphe d'héritage de UnityEngine.XR.Interaction.Toolkit.Locomotion.Comfort.LocomotionVignetteProvider:

Propriétés

LocomotionProvider locomotionProvider [get, set]
 The LocomotionProvider to trigger the tunneling vignette effects based on its LocomotionState.
bool enabled [get, set]
 Whether to enable this LocomotionProvider to trigger the tunneling vignette effects.
bool overrideDefaultParameters [get, set]
 If enabled, Unity will override the value of TunnelingVignetteController.defaultParameters and instead use the customized VignetteParameters defined by this class.
VignetteParameters overrideParameters [get, set]
 The VignetteParameters that this LocomotionVignetteProvider uses to control the vignette when the property to override TunnelingVignetteController.defaultParameters is enabled.
VignetteParameters vignetteParameters [get]
 Represents the parameter values that this provider wants to set for the tunneling vignette effect. A value of null indicates the TunnelingVignetteController.defaultParameters should be used.
