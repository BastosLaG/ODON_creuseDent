Description détaillée

A useful set of functionality commonly found in allocator performance and benchmark tests for most allocator types. Typically wrapped in a separate utility class for a set of tests to a specific allocator type.

Documentation des fonctions membres

◆ Setup()

void Unity.Collections.PerformanceTests.BenchmarkAllocatorUtil.Setup ( int workers,
int baseSize,
int growthRate,
int allocations )

To be called prior to each measurement. Sets up the allocation and size storage used for freeing allocations, whether this happens during teardown following each measurement, or freeing is the functionality being measured itself.

Paramètres
workersThe number of job workers to run performance tests on. These are duplicated across workers rather than split across workers.
baseSizeThe size to base allocations off of, whether fixed for all allocations, increasing in size, or anything else.
growthRate
  • If < 0, a performance measurement's allocations start at the largest size and decrease linearly to the baseSize.
  • If > 0, a performance measurement's allocations start at the baseSize and increase linearly
  • If 0, the allocation size is equivalent to the baseSize for all of a performance measurement's allocations
allocationsThe number of allocations in a single measurement.

◆ Teardown()

unsafe void Unity.Collections.PerformanceTests.BenchmarkAllocatorUtil.Teardown ( AllocatorManager.AllocatorHandle allocator)

To be called following each measurement. Frees the memory allocated in the Setup(int, int, int, int) method. This also frees the memory allocated by the given allocator using the stored information in this class.

Paramètres

◆ AllocSize

NativeArray<int> Unity.Collections.PerformanceTests.BenchmarkAllocatorUtil.AllocSize
get

[sequential allocation]

Used to store the size of allocations so it may be freed later, as some allocators require the size to be explicitly given when freed. Separate arrays for each worker are not provided because workers duplicate the same work rather than splitting it in some manner.
