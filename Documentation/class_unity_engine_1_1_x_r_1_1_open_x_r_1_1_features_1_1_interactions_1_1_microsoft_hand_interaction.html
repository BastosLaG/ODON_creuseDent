Description détaillée

This OpenXRInteractionFeature enables the use of Microsoft hand interaction profiles in OpenXR. It enables XR_MSFT_hand_interaction in the underyling runtime. This creates a new InputDevice with the InputDeviceCharacteristics.HandTracking characteristic.
